# ARTEM VISUALS 2.0

Клиентский мод для **Minecraft 1.21.1** (Fabric).  
Неоновые визуальные эффекты, перетаскиваемый HUD, кастомный прицел, профили настроек и пресет оптимизации FPS.

**Автор:** Artem  
**Тема:** чёрный + фиолетовый неон  
**Клавиша меню:** Right Shift  

---

## Возможности

### 1. Эффекты
- Листопад, дождь/снег, блики на воде, светлячки ночью, частицы при ломании блоков
- Мягкий свет (gamma) и сглаженное освещение
- Плотность, радиус, адаптивная пауза при низком FPS

### 2. HUD (перетаскиваемый)
- FPS, Ping, XYZ, CPS, WASD-индикатор, название сервера
- Режим редактирования: включите в вкладке HUD → перетаскивайте элементы мышью
- Позиции сохраняются в конфиг

### 3. Прицел
- Стили: крест / точка / круг / плюс
- Размер, зазор, толщина, обводка, динамическое расширение при атаке
- Палитра неоновых цветов + **предпросмотр** в меню

### 4. Оптимизация
- Пресет производительности (частицы, тени, облака, дистанция сущностей…)
- Восстановление предыдущих настроек видео
- Сброс всех настроек мода

### 5. Профили
- Сохранение / загрузка / удаление профилей в `config/artemvisuals/profiles/*.json`

Мод **не использует Mixin** → совместим с Sodium, Iris, Lithium и т.д.

## Сборка JAR

### Локально
1. JDK **21**
2. В папке проекта:
   ```bash
   # один раз
   gradle wrapper --gradle-version 8.10.2
   # сборка
   ./gradlew build          # Linux / macOS
   gradlew.bat build        # Windows
   ```
3. Готовый файл: `build/libs/artem-visuals-2.0.jar`  
   (не берите `-sources.jar`)

### Через GitHub Actions
1. Создайте репозиторий и залейте проект.
2. Workflow `.github/workflows/build.yml` сам соберёт JAR на push / вручную.
3. Скачайте артефакт **artem-visuals-jar** из вкладки Actions.

## Установка
1. Fabric Loader ≥ 0.16.5 + Fabric API 0.105.0+1.21.1
2. Положите `artem-visuals-2.0.jar` в `.minecraft/mods`
3. В игре: **Right Shift** → меню

Конфиг: `config/artemvisuals.json`  
Профили: `config/artemvisuals/profiles/`

## Структура пакетов
```
com.artem.visuals
├── ArtemVisualsClient      # точка входа
├── config/
│   ├── ArtemConfig         # JSON-настройки
│   └── ProfileManager      # профили
├── gui/
│   ├── ArtemScreen         # меню 5 вкладок
│   └── NeonButton          # неоновые кнопки
├── hud/
│   ├── HudElement          # базовый перетаскиваемый элемент
│   └── HudManager          # FPS / Ping / XYZ / CPS / WASD / Server
├── crosshair/
│   └── CrosshairRenderer   # прицел + preview
├── effects/
│   └── EffectManager       # клиентские частицы
└── optimize/
    └── Optimizer           # пресет видео + освещение
```

## Заметки
- CPS и динамический прицел реагируют на атаки (при необходимости можно добавить хук через `ClientPlayerInteractionManager` / mixin, сейчас используется встроенный счётчик кликов).
- Если при первой сборке появятся ошибки компиляции — пришлите лог, исправим точечно.
